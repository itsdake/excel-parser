# Тест-кейсы

Ручные сценарии для показа и приёмки. Файлы для проверки лежат в [`docs/examples/`](examples/) (раскладки А–Д, название таблицы, «Разные листы»; пересобрать — `node docs/examples/make-examples.cjs`). Запуск — `start.bat` или `node backend/src/main.js` → http://localhost:3000; без сервера интерфейс не работает (тонкий клиент).

Автоматические проверки: `npm test` в `backend` (175: чтение и запись xlsx, парсер, формулы, правки, диаграммы, сравнение, API) и в `frontend` (34).

## 3. Диаграммы (критерий 3)

| № | Шаги | Ожидаем |
| --- | --- | --- |
| 3.1 | «Аналитика» после загрузки `ForConstructor.xlsx` | Два блока (по листу), у каждого итоги (Σ, среднее, мин, макс) и столбчатая диаграмма |
| 3.2 | В шапке карточки по очереди нажать иконки видов | Линейная, столбчатая, круговая, точечная, гистограмма, тепловая, комбинированная; смена вида не сбрасывает заголовок и ряды |
| 3.3 | «Построить все виды» (файл В) | Добавляются недостающие виды; повторное нажатие ничего не плодит |
| 3.4 | «Добавить диаграмму» нужного вида, «Дублировать», «Удалить» | Новая карточка в конце; копия сразу после оригинала с теми же настройками; после удаления фокус на панели; данные листа не тронуты |
| 3.5 | Добавлять до 12 диаграмм | Виды, которые уже есть на листе, в панели «Добавить диаграмму» выделены синим, у вида с несколькими диаграммами — число; под панелью «Выделены виды…: N из 7». На 12-й кнопки отключаются, выделение остаётся, под панелью оранжевая причина «Достигнут предел — 12 диаграмм…», у каждой кнопки подсказка с тем же |
| 3.5а | Когда на листе есть все 7 видов | «Построить все виды» отключена, в подсказке и под панелью написано «все виды уже есть» |
| 3.6 | ⚙ у столбчатой: «Столбцы стопкой», «Значения на диаграмме», «Сортировка: по убыванию», свой заголовок | Диаграмма перестраивается, в шапке новый заголовок; на «Данных» таблица не изменилась |
| 3.7 | ⚙ → «Ряды на диаграмме»: снять один, затем все | Остаётся один ряд / сообщение «Выберите ряд в настройках диаграммы»; цвета рядов не меняются |
| 3.8 | Параметры видов: линейная — сглаживание; круговая — кольцо и ряд; точечная — ряды по X и Y; гистограмма — ряд и число интервалов; тепловая — шкала цвета; комбинированная — линия (среднее / накопленный итог / другой ряд) | Каждый параметр действует только на свою диаграмму |
| 3.8а | ⚙ → «Легенда»: клик, выбрать «Скрыть»; затем с клавиатуры: Enter, ↑ ↓, Enter; Esc; клик мимо; Tab | Список раскрывается карточкой под кнопкой, у текущего пункта галочка; значение применяется сразу; Esc, клик снаружи и Tab закрывают список без изменения; на телефоне список не выходит за экран |
| 3.8б | Воронка в шапке карточки: снять галочки у двух точек; «Инвертировать», «Ни одной», «Все» | На диаграмме остаются отмеченные точки; в панели «Показано 3 из 5 · скрыто 2», в отчёте «Точек: 3 из 5 (фильтр)», на воронке точка; «Ни одной» — «Под условия фильтра не попала ни одна точка»; таблица на «Данных» не меняется |
| 3.8в | Воронка: «Значение от» 10, «до» 35, «Оставить точек» 2 → «Наименьшие»; «Подпись содержит»; «По ряду» — другой ряд; «Сбросить фильтры» | Условия складываются, порядок точек как на листе; условия считаются по выбранному ряду; сброс возвращает все точки и убирает точку с воронки |
| 3.8г | Фильтр включён: правка значения в «Данных»; вставка строки перед скрытой точкой; Ctrl+Z; обновить страницу; «Дублировать» | Фильтр применяется к новым значениям; скрытая точка остаётся скрытой после вставки, отмена возвращает; фильтр сохраняется после перезагрузки и копируется в дубликат; в предпросмотре на «Данных» диаграммы отфильтрованы так же |

| 3.10 | Круговая на данных с нулём и отрицательным значением | Они не попадают в круг; если положительных нет — надпись «Нет положительных значений» |
